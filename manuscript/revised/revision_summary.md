## 섹션별 주요 수정 내용

### 초록 (Abstract)
- "공직사회 담론의 구조적 차이를 분석" → "언론이 재현한 공직사회 담론의 구조적 차이"
- "담론 변화를 분석" → "언론 담론의 재구성 양상을 분석"
- 분석 단위 명시 문장 추가: "본 연구의 분석 단위는 실제 공무원의 인식·태도·경험이나 공직사회 내부 조직문화의 객관적 상태가 아니라, 언론 기사에 나타난 공직사회 관련 담론이다"
- 통계 검정 비유의 결과 명시 추가

### 서론 (Introduction)
- 연구 범위 한정 문장 강화: 언론 담론 재현 방식 분석임을 명시
- 신규 분석 방법 3가지(COVID robustness, 3기간 분해, 개념군) 소개 추가
- 기여 진술에서 인과 주장 제거, 기술적 기여로 재정립

### 이론적 배경 (Theoretical Framework)
- 누적적 재구성 개념의 이론적 위치 명확화
  - Mahoney & Thelen(2010) layering: 제도 층위 → 본 연구는 담론 층위
  - Soroka(2002) issue attention cycles: 의제 주기성 → 본 연구는 의제 결합 방식의 변화
  - 언론 담론 분석의 인식론적 전제 명시
- NPM/NPG 이론 연결: 개념군(성과주의/NPM, 조직문화/NPG)과 이론 틀 연결

### 연구 설계 (Research Design)
- 개념군 사전 구성 근거 추가 (선행연구 + 귀납적 검토 병행)
- 5개 개념군 목록과 측정 방식 명시 (10,000 토큰당 정규화 빈도)
- 방법론적 삼각검증(methodological triangulation) 프레임으로 재구성
- 3기간 분해 설계의 목적: 인과 식별이 아닌 기술적 분해(descriptive decomposition)임을 명시

### 분석 결과 (Results) — 대폭 재구성
기존 구조(방법론 순서별 3개 절) → 연구 질문별 6개 절로 재편:

1. **공직사회 관련 언론 담론의 공통 기반**: 행정 운영 관련 어휘의 시기 공통성 확인
2. **정부 간 담론 차이는 존재하는가?**: 개념군 분석으로 차이 확인 (성과주의 ↓, 공정성·디지털·방역 ↑)
3. **코로나19 어휘 충격이 결과를 주도했는가?**: Robustness 검증 (토큰 제거 후 TF-IDF 보존율 1.000, log-odds 0.900, 방향 안정성 1.000)
4. **변화는 코로나 이전부터 시작되었는가?**: 3기간 분해 (공정성·디지털 전환은 Moon Early부터 증가)
5. **어떤 개념군이 누적적으로 재구성되었는가?**: 개념군별 시기별 비교 + TF-IDF/log-odds/LDA/네트워크 보조 증거
6. **소결**: 누적적 재구성의 증거 종합

### 논의 (Discussion)
- 과거 표현: "보여준다" → "시사한다", "관찰된다", "재현된다"
- 인과 주장 완화: "담론 구조 전반에 영향을 미친" → "담론 구조와 결합된 것으로 관찰된다"
- NPM 약화 논의: 실제 개혁 실패가 아닌 언론 담론에서의 상대적 가시성 변화로 재해석
- 공정성 담론 선행성 논의: 조국 사태 등 관련 사건 언급 (discourse confounder로 인식)
- 누적적 재구성 개념의 의의와 한계 논의 추가

### 정책적 함의 (Policy Implications)
- "정책적 함의를 가진다" → "정책 커뮤니케이션 및 공적 담론 관리 차원에서 함의를 제공한다"
- 실제 조직 처방 제거, 커뮤니케이션 차원으로 범위 축소
- 각 함의 항목에 "이는 언론 담론 분석의 범위 안에서 도출된 것" 명시
- "통합적 접근이 요구된다" → "통합적 커뮤니케이션 접근이 필요함을 시사한다"

### 결론 (Conclusion)
- 기여 진술에서 causal overstatement 제거
- 후속 연구 방향에 외적 타당도 확보 방안 명시 (설문, 면접, 행정자료)
- 방법론 한계 명시: N=2 정부 비교, 언론사 편향, 담론-현실 간극
