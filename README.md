## 공직사회 담론의 구조적 전환 분석: 2013~2022년 한국 언론 뉴스 빅데이터 기반 비교 토픽 네트워크 분석

### 📘 프로젝트 개요

본 연구는 박근혜정부(2013~2017)와 문재인정부(2017~2022) 시기를 대상으로,
한국 언론에서 형성된 공직사회 담론의 구조적 변화를 대규모 뉴스 데이터 기반으로 분석한다.
단순 키워드 빈도 비교를 넘어,

- TF-IDF 기반 의제 중요도 변화,
- PMI 기반 차별적 공출현 네트워크,
- LDA 토픽모델링을 통한 담론 프레임 전환 을 통합적으로 적용하여 공직 담론이 ‘제도·규제 중심’에서 ‘조직·권리·공정·근무경험 중심’으로 이동했는지를 실증적으로 검증한다.

### 연구목적

본 연구의 목적은 다음 세 가지이다.

1. 정부 시기별 공직사회 의제 구조 차이를 정량적으로 비교
2. 동일 키워드라도 어떤 맥락(관계 구조) 속에서 의미가 변화했는지 규명
3. 공직 담론이 제도 개혁 중심 → 조직문화·권리·근무경험 중심으로 이동했는지 검증
   이를 통해 향후 공직제도 개편 및 정책 커뮤니케이션 전략에 대한 실증적 시사점을 도출하고자 한다.

### 연구이론 및 개념적 논의

1. 신공공관리론(NPM) vs 거버넌스 이론 — 효율·성과 중심 관리에서 참여·권리·조직문화로의 전환

2. 의제설정이론 & 프레이밍 이론 — 단어 빈도가 아닌 ‘연결 구조’와 ‘주제 묶음’의 변화에 주목

3. 조직 변화 이론(Lewin, Kotter) — 공직 담론에서 ‘개혁’이 어떻게 재정의되는지 해석

7️⃣ 공출현 네트워크 분석 (10_cooccurrence_network.py)

목적:

- 기사 내 단어쌍의 공출현(co-occurrence) 빈도를 계산하고, 단어 간 관계를 NetworkX 기반 그래프로 시각화

공출현 네트워크(co-occurrence network)는 기사 단위(window size = 전체 문서)를 기준으로 계산하였다. 즉, 동일 기사 내에서 함께 등장한 단어쌍을 하나의 공출현 관계로 간주하여 edge를 구성하였다. 이는 문장 단위(window size = sentence-level)에 비해 담론 단위 의미 구조를 더 안정적으로 반영한다.
정책·조직 담론 분석에서는 개별 문장이 아닌 기사 전체가 하나의 의미 단위(discursive unit)로 기능하기 때문에, 문서 단위 공출현이 담론 구조 변화와 중심 개념의 상관성을 더 잘 나타낸다. 반면 문장 단위 window는 지나치게 미시적 granular 분석이 되어, 시간·시대 담론 비교에는 적합하지 않다는 특성이 있다.

```
pairs = []
for words in df['nouns']:
    pairs += list(combinations(set(words), 2))
counter = Counter(pairs)
G = nx.Graph()
for (a, b), w in counter.items():
    G.add_edge(a, b, weight=w)

```

출력: network_2015_2019.png, network_2020_2024.png, \_edges.csv, \_centrality.csv
